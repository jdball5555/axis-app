# Changelog

All notable changes to this project are listed here, newest first.
Versions follow [Semantic Versioning](https://semver.org): **major** for redesigns, **minor** for new features, **patch** for fixes.

## [0.8.0] — 2026-03-18

### Added
- Analytics hub, combining the stats and inventory pages
- Fitbit data sync

### Changed
- Updated inventory page
- Nightly debrief and sleep tracking updates

### Fixed
- Settings page column layout

## [0.7.0] — 2026-02-22

### Added
- Finances page
- Receipt scanner with itemized AI parsing
- Nightly debrief form and sleep tracking
- Morning briefing with weather

### Changed
- Archived the AI chat module (hidden from the app and the repository)

### Fixed
- Notification bugs

## [0.6.0] — 2026-01-19

### Added
- Home page customization: toggle and reorder tiles

### Changed
- Moved notification logic to Cloud Functions
- Reworked the settings page
- Unified item calculations across multiple rooms

### Fixed
- Inventory sharing reliability
- Switching between multiple inventories

## [0.5.0] — 2026-01-06

### Added
- Shared lists

### Changed
- Smarter notifications
- About page shows the sync feature and updated "What's new"

### Fixed
- Horizontal scrolling of active rooms in notification settings

## [0.4.0] — 2025-12-28

### Added
- Interactive timeline graph on the stats page, with date editing by long-press
- Firebase Authentication and Firestore for multi-user cloud sync
- Account section and dynamic version number in settings

### Fixed
- Removed unused variables and the test notification button

## [0.3.0] — 2025-12-26

### Added
- Light and dark themes with animated switching
- Color options

### Changed
- Swipe horizontally between pages

## [0.2.0] — 2025-12-16

### Added
- Notification settings

## [0.1.0] — 2025-12-15

### Added
- First version: home, inventory, stats, activity log, morning and night pages, local notifications
